# JavaScript Practicals

20 separate JavaScript practice programs, grouped by learning day.

- **Day 05 — Basics:** Practical 01–08 (variables, calculations, conditions, functions and loops)
- **Day 06 — Arrays, Objects & DOM:** Practical 09–17
- **Day 07 — Async & API:** Practical 18–20

Run console-based files with Node.js, for example:

```powershell
node .\Day-05-Basics\01-clinic-information.js
```

All names, fees and records in these exercises are fictional demo data.
