# HealthCare Clinic Website

A responsive demo clinic website built using HTML5 and CSS3.

## Features
- Navigation links and hero section
- About, services and sample doctor sections
- Demo appointment enquiry form
- Contact section and footer
- Flexbox layout and mobile media query

## Run Locally
Open `index.html` in a browser.

## Important
This is a front-end learning project. The form does not send or store appointments. Clinic details, contact details and doctor profiles are sample content only.
